A program that writes one funny passive-aggressive note a smart fridge leaves for its owner: a single dry, petty, specific line for the door screen. A judge model compares the lines two at a time and the funniest takes the reward.

## Run it

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt` (`$OUTPUT_DIR` overrides the directory).
